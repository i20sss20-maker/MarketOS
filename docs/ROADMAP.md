# MarketOS roadmap

## Phase 0 — Foundation

- monorepo and CI
- chart prototype
- provider-neutral market data contracts
- Azure Functions API boundary
- AI gateway design
- demo data only

## Phase 1 — Real market data

- evaluate licensed market-data vendors
- symbol search
- OHLCV history
- streaming quotes
- watchlists
- chart persistence
- market status and sessions

## Phase 2 — Professional charting

- multi-chart layouts
- indicators
- drawing tools
- templates
- alerts
- replay
- screeners
- heatmaps

## Phase 3 — AI-native chart workflow

- ask the chart
- support/resistance overlays
- multi-timeframe context
- natural-language screener
- explain market movement
- AI-generated indicators with validation
- source-aware answers

## Phase 4 — Mobile

- iPhone/iPad
- Android phone/tablet
- account sync
- alerts and push notifications

## Out of scope for now

- brokerage
- order execution
- custody
- handling client funds
